## Что под капотом

- **ID:** `fileId` = SHA-256 содержимого .docx, `questionId` = SHA-256 нормализованного вопроса + правильного ответа (`src/utils/ids.ts`). Тот же вопрос в другом файле или исправленной версии банка узнаётся. Дубль файла ловится и по содержимому, а не только по имени.
- **Миграция:** файлы, сохранённые прошлой версией, получают ID при первом открытии главной.
- **История:** `src/utils/studyStore.ts` — попытки (`attempts`, до 300) и статус каждого вопроса (`questionStats`) в IndexedDB. Повторное открытие страницы результатов статистику не задваивает.
- **Конвертер** использует те же ID — история общая.
- **Метрика:** параметры визита `inapp` (telegram / instagram / none), `standalone`, `ref`; 5 новых целей (`mistakes_mode_start`, `attempt_saved`, `a2hs_hint_shown`, `a2hs_hint_closed`, `data_wiped`) заведены через API. Все 25 событий из кода есть в Метрике.
- Исправлено попутно: плашка «Незаконченный тест» больше не появляется после «Завершить тест»; в тексте для Telegram был пропущен пробел после двоеточия.

## Как проверено

Браузер на ширине телефона (375px), dev-сервер:
- миграция старого сохранённого файла → ID проставлены;
- загрузка 2 файлов + копия под другим именем → «уже загружали»;
- тест из 15 вопросов, 4 ошибки → попытка записана, «Работа над ошибками (4)»; перезагрузка результатов → без задвоения;
- режим ошибок: 4 вопроса, 2 исправлено, 1 снова неверно → осталось 2;
- главная: статистика по файлам, полоска готовности;
- `/privacy` → «Стереть» → IndexedDB удалена;
- подсказка iOS с подменённым user agent → показалась, закрылась, запомнилась;
- конвертер → тест с ID;
- сетевые запросы: только навигация Next.js и Метрика, содержимого файлов нет;
- `tsc`, `eslint` (0 ошибок, 4 старых предупреждения), `next build` — ок.

## Что НЕ проверено

- Живой iPhone: Safari, встроенный браузер Telegram, запуск с экрана «Домой». Нужно перед выкаткой в пик.
- Попадание параметров визита `inapp`/`ref` в отчёты Метрики — видно через сутки после выкатки.
- `storage.persist()` — на iOS ничего не гарантирует, эффект не измерить.

## Ограничения, о которых стоит знать

- «Работа над ошибками» на главной берёт вопросы только из загруженных на главной файлов; на странице результатов — ещё и из теста, запущенного из конвертера.
- «Знаю» = 2 верных ответа подряд; один верный ответ — «в процессе», в строке не показывается.
- Цель «клик „Начать тест“ без файла» больше не срабатывает (кнопка неактивна без файла) — это ожидаемо.
