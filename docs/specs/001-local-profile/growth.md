# Распространение: план на декабрьскую сессию 2026

Цены рекламы ниже — оценки, не проверены.

## Принципы
- Позиционирование: **«тренажёр для своего банка вопросов»**, не «ответы Platonus». Банки вопросов мы не публикуем.
- Продукт уже распространяется через чаты групп (Direct ~80%, вернувшиеся 62%). Задача — чтобы ссылка ходила вместе с .docx и это было видно в аналитике.
- Каждый посев — со своей UTM: `utm_source=tg&utm_medium=chat&utm_campaign=dec26&utm_content=<вуз_город>`.

## Монетизация
- Рекламу на сайт не ставить: при ~12 тыс визитов в год это десятки долларов и потеря доверия.
- Можно: ненавязчивая кнопка «Поддержать» (Kaspi) на экране результатов — заодно проверка ценности.

## Что измеряем в декабре
- Доля `inapp=telegram` в параметрах визитов.
- Новые визиты с `ref=share` / `ref=group_msg` / `ref=result_tg` и по каждой UTM-кампании.
- Воронка по UTM: визит → файл загружен → тест завершён.
- Пиковая неделя против прошлого декабря (~500 визитов). Ориентир — ×1,5–2 (оценка).
